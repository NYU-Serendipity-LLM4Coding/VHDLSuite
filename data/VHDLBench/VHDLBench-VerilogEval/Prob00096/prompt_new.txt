Implement a finite-state machine that searches for the sequence 1101 in an input bit stream. When the sequence is found, the module should assert the start_shifting output and hold it high indefinitely until reset.

Module name:
    TopModule

Input ports:
    clk: Clock signal for synchronous operation
    reset: Synchronous reset signal, active high
    data: Serial input bit stream to be monitored for the target sequence

Output ports:
    start_shifting: Status flag that asserts high when the sequence 1101 has been detected; remains high until reset

Implementation:
    The module implements a Mealy-style finite-state machine with five distinct states to detect the bit pattern 1101. The FSM begins in an idle state and progressively transitions through intermediate states as each bit of the target sequence is recognized on the data input. 

    The state machine operates as follows: Initially, the FSM waits in the idle state until a '1' is detected on the data input, which triggers a transition to the first recognition state. A subsequent '1' advances to the second state, representing detection of "11". From this state, receiving a '0' moves to the third state (sequence "110" detected), while another '1' keeps the machine in the second state to handle overlapping patterns. Upon detecting a final '1' while in the third state, the complete sequence "1101" is confirmed, and the FSM enters a terminal done state. Once in the done state, the machine remains there permanently, regardless of further input, until reset is applied.

    The design uses a two-process architecture: one combinational process determines the next state based on the current state and data input, while a sequential process updates the state register on each rising clock edge. The synchronous reset has priority and forces the state machine back to the idle state when asserted high.

    The start_shifting output is generated by combinational logic that decodes the current state, asserting high only when the FSM is in the done state, thereby indicating successful sequence detection.
