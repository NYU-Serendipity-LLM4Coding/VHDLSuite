Declaration:
    This design requires the IEEE standard logic library to support the fundamental digital logic types and operations used throughout the implementation. Specifically, the std_logic_1164 package is necessary to provide the std_logic type for representing individual signal values with multiple logic levels, including high, low, and undefined states. This package also supplies the std_logic_vector type for representing multi-bit buses, though this particular design uses only scalar signals. The standard logic types enable proper modeling of synchronous digital circuits with defined clock edge detection and reset behavior.
