Declaration:
    This design requires the IEEE standard logic library to support the fundamental logic types and operations used throughout the implementation. Specifically, the std_logic_1164 package is necessary to provide the std_logic type for representing digital signal levels and logic values in the port interface and internal signals. This package enables the definition of single-bit logic signals that can represent states beyond simple binary values, including high-impedance and unknown conditions, which are essential for proper hardware modeling and simulation of the finite state machine.
