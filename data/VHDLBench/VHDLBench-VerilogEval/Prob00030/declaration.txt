Declaration:
    This design requires the IEEE standard logic library to define the std_logic and std_logic_vector types used for the input and output ports. Additionally, the IEEE numeric_std package is necessary to provide arithmetic operations and type conversions, specifically the to_unsigned function for converting integer values to unsigned vectors, and the std_logic_vector conversion for output assignment. These standard VHDL libraries enable the representation of multi-bit logic signals and support the integer arithmetic needed to accumulate the population count result.
