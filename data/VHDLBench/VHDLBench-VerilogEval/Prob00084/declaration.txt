Declaration:
    This VHDL design requires the IEEE standard logic library to support the fundamental digital logic types used throughout the module. Specifically, the std_logic_1164 package provides the std_logic and std_logic_vector types necessary for representing single-bit and multi-bit signals in the design. Additionally, the numeric_std package is required to enable arithmetic operations and type conversions on std_logic_vector signals, particularly for converting address vectors to integer indices when performing array indexing operations in the multiplexer selection logic.
