Declaration:
    This design requires the IEEE standard logic library to support fundamental digital logic types including std_logic and std_logic_vector, which represent single-bit and multi-bit logic signals respectively. Additionally, the numeric_std package is included to provide support for numeric operations and type conversions involving std_logic_vector types, though the primary functionality relies on enumerated state types and basic logic operations. These standard IEEE libraries provide the necessary infrastructure for describing synchronous digital systems with defined logic values and multi-bit data buses.
