Declaration:
    This design requires the IEEE standard logic library to support the fundamental logic types and operations used throughout the implementation. Specifically, the `std_logic_1164` package is necessary to provide the `std_logic` type for individual signal lines and the `std_logic_vector` type for multi-bit buses. These types enable proper modeling of digital logic values including driven states, high-impedance conditions, and uninitialized values. The package also supplies essential logical operators and the `rising_edge` function used to detect clock edges in synchronous processes.
