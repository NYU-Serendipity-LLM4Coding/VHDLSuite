Declaration:
    This VHDL design requires the IEEE standard logic library to support multi-valued logic types and vector operations. Specifically, the `ieee.std_logic_1164` package is necessary to provide the `std_logic` and `std_logic_vector` types used for the input and output port declarations. These types enable representation of digital signals with standard logic values and support the concatenation and aggregate assignment operations needed to perform sign extension from an 8-bit input vector to a 32-bit output vector.
