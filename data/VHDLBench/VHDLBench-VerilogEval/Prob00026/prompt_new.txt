Implement a module that performs a logical AND operation on two single-bit inputs and produces the result using two different VHDL coding styles.

Module name:
    TopModule

Input ports:
    a: Single-bit input signal (std_logic), first operand of the AND operation
    b: Single-bit input signal (std_logic), second operand of the AND operation

Output ports:
    out_assign: Single-bit output signal (std_logic), result of AND operation implemented using concurrent assignment
    out_alwaysblock: Single-bit output signal (std_logic), result of AND operation implemented using a combinational process

Implementation:
    This module demonstrates two equivalent methods for implementing combinational logic in VHDL. Both outputs produce the logical AND of inputs a and b, but use different coding constructs.

    The first output, out_assign, is driven by a concurrent signal assignment statement. This is a direct, continuous assignment that evaluates whenever either input changes.

    The second output, out_alwaysblock, is driven by a combinational process with a sensitivity list containing both inputs a and b. The process executes whenever either signal in the sensitivity list changes, re-evaluating the AND operation and updating the output.

    Both methods are purely combinational with no clock or reset signals. The module operates asynchronously, responding immediately to changes on either input. The two outputs will always produce identical logical results, demonstrating that VHDL provides multiple equivalent ways to describe the same hardware behavior.
