Declaration:
    This VHDL design requires the IEEE standard logic library to support fundamental digital logic operations. Specifically, the design uses the std_logic_1164 package, which provides the std_logic type for representing individual logic signals and the std_logic_vector type for representing buses or multi-bit signals. These types enable the representation of binary values and support basic logical operations such as AND, OR, and NOT, which are essential for implementing the combinational logic derived from the Karnaugh map. No additional libraries or packages beyond the IEEE standard logic support are necessary for this design.
