Declaration:
    This design requires the IEEE standard logic library to define the fundamental digital logic types used throughout the module, including std_logic for individual signal bits and std_logic_vector for multi-bit buses representing the game grid state and input data. The numeric_std package is essential for performing arithmetic operations on vectors, specifically to compute neighbor counts by summing individual cell values, performing bitwise logic operations on unsigned quantities, and resizing single-bit values to multi-bit unsigned representations for accumulation. These libraries provide the necessary type definitions and operator overloading to support the combinatorial neighbor-counting logic and the state update rules that govern the cellular automaton behavior on the toroidal grid.
