Declaration:
    This design requires the IEEE standard logic library to support multi-valued logic types and vector operations. Specifically, the `ieee.std_logic_1164` package is needed to define `std_logic` and `std_logic_vector` types, which represent individual bits and bit vectors respectively. These types enable the use of logical operators (AND, OR, XOR) on vector elements to perform bitwise comparisons between neighboring bits in the input vector. No arithmetic or conversion packages are required, as the design performs only combinational logic operations without numerical computations.
