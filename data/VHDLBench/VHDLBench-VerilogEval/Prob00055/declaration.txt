Declaration:
    This design requires the IEEE standard logic library to support multi-valued logic types and vector representations. The std_logic_1164 package provides the fundamental std_logic and std_logic_vector types used for all port signals. Additionally, the numeric_std package is necessary to enable arithmetic comparisons on unsigned integer values, as the design performs relational operations (greater-than comparisons) on 8-bit vectors interpreted as unsigned numbers. This package provides the unsigned type and conversion functions between std_logic_vector and unsigned representations, allowing proper numerical comparison semantics for finding the minimum value among multiple inputs.
