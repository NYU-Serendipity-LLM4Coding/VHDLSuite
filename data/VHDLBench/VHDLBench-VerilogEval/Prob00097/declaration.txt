Declaration:
    This design requires the IEEE standard logic library to support the fundamental logic types used throughout the module. Specifically, the std_logic_1164 package is necessary to define multi-valued logic signals and vector types that represent the data inputs and outputs. Additionally, the numeric_std package is required to enable interpretation and manipulation of logic vectors as numeric values, supporting the selection mechanism that compares the selector input against specific numeric patterns to determine which data input should propagate to the output.
