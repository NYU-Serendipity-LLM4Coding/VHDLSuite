Implement a module that performs combinational logic operations using a two-layer gate structure with both normal and inverted outputs.

Module name:                 
    TopModule

Input ports:
    a: First input to the first AND gate, single-bit std_logic
    b: Second input to the first AND gate, single-bit std_logic
    c: First input to the second AND gate, single-bit std_logic
    d: Second input to the second AND gate, single-bit std_logic

Output ports:
    signal_out: The result of the two-layer logic operation, single-bit std_logic, active high
    signal_out_n: The inverted result of signal_out, single-bit std_logic, active high

Implementation:
    The module implements a combinational logic circuit organized in two distinct layers. In the first layer, two AND operations are performed in parallel: one computes the logical AND of inputs a and b, while the other computes the logical AND of inputs c and d. These intermediate results are connected through internal signals to the second layer.

    The second layer consists of an OR gate that combines the two AND results from the first layer. The output of this OR operation drives the signal_out port, producing a high level when either of the AND conditions is satisfied.

    Additionally, the module provides an inverted output signal_out_n, which is the logical complement of signal_out. This inverted output is generated by applying a NOT operation directly to signal_out.

    The overall logic function can be summarized as: signal_out becomes high when either (a AND b) is true OR (c AND d) is true. The signal_out_n provides the opposite polarity of this result.

    Two intermediate signals (w1 and w2) are used internally to connect the first-layer AND gates to the second-layer OR gate, maintaining clear signal flow and modularity in the design. The implementation is purely combinational with no clocking or state elements involved.
