Declaration:
    This design requires the IEEE standard logic library to support multi-valued logic types including the fundamental std_logic and std_logic_vector types used for port declarations and internal signal representations. The numeric_std package from the IEEE library provides support for arithmetic operations and type conversions on vectors, enabling manipulation of binary values and numeric comparisons within the finite state machine logic. These standard VHDL libraries are essential for implementing the synchronous sequential logic, combinational state transitions, and output encoding required by the water level control system.
