    This design requires the IEEE standard logic library to provide the fundamental logic types and operations for digital hardware description. Specifically, it uses the standard logic package for defining signal types that represent hardware logic levels and multi-valued logic states. Additionally, the design requires numeric support for performing arithmetic operations on vector types, including unsigned arithmetic for counter implementations and vector-to-integer conversions. These standard libraries enable the representation of bit vectors, the definition of enumerated state machine types, arithmetic increment and decrement operations on counters, and comparisons between numeric values.
