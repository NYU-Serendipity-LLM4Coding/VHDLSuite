Declaration:
    This design requires the IEEE standard logic library to support the fundamental digital logic types used in VHDL designs. Specifically, the std_logic_1164 package provides the std_logic type for representing individual signal values and the std_logic_vector type for representing multi-bit buses. The numeric_std package is included to enable arithmetic and comparison operations on std_logic_vector types when interpreted as unsigned or signed values, though in this particular design it primarily supports potential type conversions and standard numeric operations that may be useful for state machine implementations.
