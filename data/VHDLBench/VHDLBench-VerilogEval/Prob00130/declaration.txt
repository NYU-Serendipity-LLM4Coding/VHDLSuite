Declaration:
    This design requires the IEEE standard logic library to support multi-valued logic types including std_logic and std_logic_vector, which represent individual bits and bit vectors respectively. The numeric_std package is necessary to provide arithmetic operations and type conversions for std_logic_vector types, specifically enabling conversion between std_logic_vector and unsigned integer representations for use in conditional selection logic. These standard packages allow the design to perform vector-based signal routing and integer-based case discrimination.
