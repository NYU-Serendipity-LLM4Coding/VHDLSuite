    This VHDL design requires the IEEE standard logic library to support multi-valued logic types and vector operations. The std_logic_1164 package provides the fundamental std_logic and std_logic_vector types used for all port declarations and internal signals. Additionally, the numeric_std package is included to enable arithmetic operations and type conversions on standard logic vectors, supporting the manipulation of byte-wide data and multi-byte message assembly within the datapath.
