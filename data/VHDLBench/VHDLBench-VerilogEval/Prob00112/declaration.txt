Declaration:
    This VHDL design requires the IEEE standard logic library to support the std_logic and std_logic_vector types used for digital signal representation. The ieee.std_logic_1164 package provides the fundamental logic value system including multi-valued logic states. Additionally, the ieee.numeric_std package is included to enable arithmetic operations and type conversions on std_logic_vector types, supporting unsigned and signed interpretations of binary vectors when needed for computational purposes.
