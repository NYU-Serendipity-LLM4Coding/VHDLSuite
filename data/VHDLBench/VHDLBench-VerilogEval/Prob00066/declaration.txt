Declaration:
    This design requires the IEEE standard logic library to provide the fundamental logic types and operations used throughout the implementation. Specifically, the std_logic_1164 package is necessary to support the std_logic type for individual signals and the std_logic_vector type for multi-bit buses. This package enables the use of standard logic values, logical operators (such as AND, OR, and NOT), and vector operations essential for implementing the edge detection and capture logic. No additional arithmetic, numeric conversion, or non-standard libraries are required for this design, as it operates purely on boolean logic and bit-wise operations.
