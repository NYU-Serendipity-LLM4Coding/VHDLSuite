Implement an asynchronous FIFO module with configurable bit width and depth. The FIFO is designed to operate across two independent clock domains (write and read) and uses Gray code pointers for safe clock domain crossing. The design consists of a dual-port RAM for storage and comprehensive control logic for pointer management, synchronization, and status flag generation.

Module name:  
    TopModule

Input ports:
    wclk: Write clock signal, used to synchronize write operations.
    rclk: Read clock signal, used to synchronize read operations.
    wrstn: Active-low asynchronous reset for the write clock domain. When '0', the write-side logic is reset.
    rrstn: Active-low asynchronous reset for the read clock domain. When '0', the read-side logic is reset.
    winc: Write increment signal. When asserted high along with wfull being low, triggers a write operation.
    rinc: Read increment signal. When asserted high along with rempty being low, triggers a read operation.
    wdata: Write data input bus, configurable width (default 8 bits), carries the data to be written into the FIFO.

Output ports:
    wfull: Write full status flag. Asserted high when the FIFO is full and cannot accept additional write operations.
    rempty: Read empty status flag. Asserted high when the FIFO is empty and no data is available for reading.
    rdata: Read data output bus, configurable width (default 8 bits), provides the data read from the FIFO.

Generics:
    WIDTH: Configurable data bus width (default 8 bits).
    DEPTH: Configurable FIFO depth (default 16 entries).

Implementation:
The module implements an asynchronous FIFO using a dual-port RAM instance and sophisticated pointer management to safely handle operations across independent clock domains.

Dual-Port RAM:
The design instantiates a dual-port RAM entity named dual_port_RAM with configurable depth and width. This RAM provides independent write and read ports, each with its own clock, enable, address, and data signals. The RAM stores data in an internal array and supports concurrent write and read operations on different clock edges. Write operations occur on the rising edge of wclk when the write enable is high, and read operations occur on the rising edge of rclk when the read enable is high.

Binary and Gray Code Pointers:
The module maintains separate binary address counters for write (waddr_bin) and read (raddr_bin) operations. These are (ADDR_WIDTH+1)-bit unsigned counters that increment when their respective increment signals are active and the FIFO is not full (for writes) or empty (for reads). The extra bit beyond the address width enables full/empty detection by tracking pointer wraparound. Both counters reset to zero on their respective asynchronous resets.

Each binary pointer is converted to Gray code using an XOR operation between the binary value and its right-shifted version. These Gray code representations (waddr_gray and raddr_gray) are then registered to create stable Gray code pointers (wptr and rptr) that are safe to synchronize across clock domains. Gray code ensures that only one bit changes at a time during pointer updates, preventing metastability issues during clock domain crossing.

Clock Domain Crossing Synchronization:
To safely compare pointers across clock domains, the module implements two-stage synchronizers. The read pointer (rptr) is synchronized into the write clock domain through a two-register chain (rptr_buff and rptr_syn), both reset to zero on wrstn. Similarly, the write pointer (wptr) is synchronized into the read clock domain through wptr_buff and wptr_syn, both reset to zero on rrstn. This double-flop synchronization reduces the probability of metastability to negligible levels.

Full and Empty Detection:
The wfull status flag is generated by comparing the write pointer with a modified version of the synchronized read pointer. Specifically, the FIFO is full when the write pointer equals the read pointer with its two most significant bits inverted. This condition indicates that the write pointer has wrapped around and caught up to the read pointer, filling all FIFO locations.

The rempty status flag is asserted when the read pointer equals the synchronized write pointer in the read clock domain, indicating that all written data has been read and no new data is available.

RAM Control and Address Mapping:
The write enable signal (wen) is generated as the logical AND of winc and the complement of wfull, ensuring writes only occur when requested and space is available. Similarly, the read enable signal (ren) is generated from rinc and the complement of rempty. The actual RAM addresses are derived from the lower ADDR_WIDTH bits of the binary pointers, effectively using modulo-DEPTH addressing. These enable signals and addresses control the dual-port RAM instance, managing actual data storage and retrieval operations.
