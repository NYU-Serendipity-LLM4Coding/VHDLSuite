Implement a module that performs fractional frequency division of an input clock signal. This frequency divider generates an output clock with a fractional division ratio of 3.5x (dividing the input frequency by 3.5), utilizing dual-edge clocking techniques to achieve half-integer division ratios while maintaining balanced timing characteristics.

Module name:                 
    freq_divbyfrac

Input ports:
    clk: Input clock signal used for synchronization and frequency division.
    rst_n: Active-low asynchronous reset signal used to initialize the module.

Output ports:
    clk_div: Fractionally divided clock output signal with a frequency that is 1/3.5 times the input clock frequency.

Implementation:
    The module implements fractional frequency division through a combination of cycle counting and dual-edge signal generation. A 4-bit counter cycles through values from 0 to 6 (a total of 7 counts), controlled by a configurable parameter set to 7. The counter resets asynchronously when the reset signal is asserted low, and increments on each rising edge of the input clock, wrapping back to zero after reaching the maximum count.
    
    Two intermediate clock signals are generated using both rising and falling edges of the input clock to create the fractional division effect. The first intermediate signal is generated synchronously with the rising edge of the input clock and produces pulses at specific counter values: when the counter equals 0 and when it equals 4 (derived from integer division of the parameter by 2, plus 1). This creates alternating periods of different durations.
    
    The second intermediate signal is generated synchronously with the falling edge of the input clock, producing pulses when the counter equals 1 and when it equals 4. This falling-edge-triggered signal provides phase-shifted pulses that complement the rising-edge signal.
    
    The final divided clock output is formed by logically combining these two intermediate signals using an OR operation. This dual-edge technique effectively creates a clock output with non-integer division, where the output toggles at intervals that alternate between different numbers of input clock cycles, producing an average division ratio of 3.5. The result is a fractionally divided clock signal with improved duty cycle characteristics compared to single-edge division methods.
