Implement a frequency divider module that takes an input clock frequency of 100MHz and generates three output clock frequencies: 50MHz, 10MHz, and 1MHz.

Module name:  
    freq_div      

Input ports:
    CLK_in: Input clock signal (100MHz)
    RST: Asynchronous active-high reset signal

Output ports:
    CLK_50: Output clock signal at 50MHz (input frequency divided by 2)
    CLK_10: Output clock signal at 10MHz (input frequency divided by 10)
    CLK_1: Output clock signal at 1MHz (input frequency divided by 100)

Implementation:
The module implements three independent clock divider circuits, each using counter-based frequency division with asynchronous reset capability.

CLK_50 generation (divide-by-2):
This output toggles on every rising edge of the input clock. An internal signal tracks the current state and inverts itself with each clock cycle, producing a 50% duty cycle output at half the input frequency. When the reset signal is asserted, the output is cleared to logic low.

CLK_10 generation (divide-by-10):
This output uses a 4-bit counter to track clock cycles. The counter increments on each rising edge of the input clock. When the counter reaches a value of 4, the output signal toggles and the counter resets to zero. This creates a complete toggle cycle every 10 input clock periods, producing a 10MHz output with a 50% duty cycle. During reset, both the output signal and counter are cleared.

CLK_1 generation (divide-by-100):
This output employs a 7-bit counter for frequency division. The counter increments with each input clock edge. When the counter reaches 49, the output toggles and the counter resets to zero. This toggling pattern occurs every 100 input clock cycles, generating a 1MHz output with a 50% duty cycle. Both the output and counter are reset to zero when the reset signal is active.

All three divider circuits operate independently and synchronously with the input clock, utilizing asynchronous reset for immediate initialization. The design ensures clean clock outputs suitable for driving other synchronous logic circuits.
