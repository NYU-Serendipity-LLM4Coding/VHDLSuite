Entity name:
    ROM

Input ports:
    addr [7:0]: 8-bit address input of type std_logic_vector used to select the data location in memory.

Output ports:
    dout [15:0]: 16-bit output of type std_logic_vector that delivers the data stored in the ROM at the specified address.

Implementation:

The addr input is converted from std_logic_vector to an integer using the to_integer and unsigned functions from the numeric_std library, which then serves as the index to access the corresponding location in the constant memory array. The selected 16-bit data value is directly assigned to the dout output port.

    Since this is a ROM implementation, the memory contents are fixed at synthesis time and cannot be modified during operation. The design provides single-cycle read access with no clock requirement, making it purely combinational logic. The address-to-data mapping happens immediately whenever the addr input changes.
