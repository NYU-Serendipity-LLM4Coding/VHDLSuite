Declaration:
    This design requires the IEEE standard logic library, which provides the fundamental logic types and operations necessary for digital circuit description. Specifically, the std_logic type and std_logic_vector type are used to represent single-bit and multi-bit digital signals respectively. These types support logical operations including AND, OR, XOR, and their vector equivalents. The standard logic package also enables the use of common logic values such as '0' and '1' for initialization and constant assignment. No additional arithmetic packages or non-standard libraries are required for this design, as all operations are performed using basic Boolean logic on individual bits and bit vectors.
