Implement a Last-In-First-Out (LIFO) buffer for temporary data storage. This 4-bit wide buffer can hold up to 4 entries, allowing for push and pop operations controlled by read/write signals.

Module name:
    LIFObuffer

Input ports:
    dataIn [3:0]: 4-bit input data to be pushed onto the buffer.
    RW: Read/Write control signal (active high for read operation, active low for write operation).
    EN: Enable signal to activate buffer operations (active high).
    Rst: Active high reset signal to initialize the buffer.
    Clk: Clock signal for synchronous operations.

Output ports:
    EMPTY: Flag indicating whether the buffer is empty (active high).
    FULL: Flag indicating whether the buffer is full (active high).
    dataOut [3:0]: 4-bit output data retrieved from the buffer.
