Implement a traffic light controller module that manages a vehicular traffic light with red, yellow, and green indicators, along with a pedestrian crossing request feature.

Module name:  
    traffic_light

Input ports:
    rst_n: Active-low asynchronous reset signal
    clk: Clock signal for synchronous operation
    pass_request: Pedestrian crossing request signal (active high)

Output ports:
    clock[7:0]: 8-bit output providing the current countdown timer value
    red: Traffic light red indicator output (active high)
    yellow: Traffic light yellow indicator output (active high)
    green: Traffic light green indicator output (active high)

Implementation:

The module implements a state machine-based traffic light controller with four states: idle, s1_red, s2_yellow, and s3_green. The controller operates with a countdown timer that manages the duration of each light phase.

Under normal operation, the traffic light cycles through the following sequence: green light for 60 clock cycles, yellow light for 5 clock cycles, and red light for 10 clock cycles. The state machine transitions between states based on the countdown timer reaching a threshold value of 3.

The pedestrian request feature modifies the green light duration dynamically. When pass_request is asserted during the green phase, if the remaining green time exceeds 10 clock cycles, the timer is immediately shortened to 10 cycles. If the remaining time is already 10 cycles or less, the timer continues counting down normally.

The module uses internal signals p_red, p_yellow, and p_green to determine the next state of each light indicator. These signals are generated by the state machine and are registered to produce the final output signals on the next clock cycle, ensuring clean, glitch-free outputs.

The countdown timer is implemented as an 8-bit counter that decrements on each clock cycle. The timer is automatically reloaded with the appropriate duration (60, 5, or 10) when transitioning between light phases, detected by comparing the current output state with the internal next-state signals.

All sequential logic operates on the rising edge of the clock signal with asynchronous active-low reset. Upon reset, the module initializes to the idle state with all lights off and the timer set to 10, then immediately transitions to the red light state on the first clock cycle.
